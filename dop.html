1. Переменные в Python: что это и как работают

Переменная в Python — это именованная область памяти, предназначенная для хранения данных. Каждой переменной присваивается определенное значение, которое может изменяться в ходе выполнения программы. Проще говоря, переменная — это "контейнер" для данных.

Особенности переменных в Python:

  • Не требуют явного объявления типа (динамическая типизация)
  • Создаются в момент присваивания значения
  • Могут менять тип в ходе выполнения программы (хотя это не рекомендуется)

Примеры создания переменных:

age = 25 # Целое число name = "Анна" # Строка temperature = 36.6 # Дробное число is_student = True # Логическое значение

2. Ввод и вывод данных: основные функции

Функция input() — для ввода данных

Функция input() позволяет получать данные от пользователя через клавиатуру. Важно помнить: эта функция всегда возвращает данные в виде строки (тип str), даже если пользователь вводит числа.

Синтаксис:

user_input = input("Подсказка для пользователя: ")

Пример с преобразованием типа:

# Ввод числа с преобразованием age = int(input("Сколько вам лет? ")) # Преобразуем строку в число print(f"Через год вам будет {age + 1} лет")

Функция print() — для вывода данных

Функция print() выводит информацию на экран.

Примеры использования:

print("Привет, мир!") # Простой вывод текста print("Имя:", name, "Возраст:", age) # Вывод нескольких значений print(f"Имя: {name}, Возраст: {age}") # f-строки (форматированный вывод)

3. Циклы в Python: while и for

Цикл while — выполняется пока условие истинно

Цикл while повторяет блок кода до тех пор, пока заданное условие остается истинным (равным True).

Синтаксис:

while условие: # Выполняемые действия

Пример:

count = 0 while count < 5: print(f"Итерация номер {count}") count += 1 # Увеличиваем счетчик, чтобы избежать бесконечного цикла
Ключевые моменты: Условие проверяется перед каждой итерацией. Важно предусмотреть изменение условия, иначе цикл станет бесконечным.

Цикл for — для перебора последовательностей

Цикл for используется для последовательного перебора элементов коллекции (списка, строки, кортежа и т.д.) или для выполнения фиксированного числа итераций.

Синтаксис:

for элемент in последовательность: # Действия с элементом

Примеры:

# Перебор списка fruits = ["яблоко", "банан", "апельсин"] for fruit in fruits: print(fruit)
# Перебор с range() for i in range(3): # 0, 1, 2 print(f"Шаг {i}")

Функция range():

range(5) # 0, 1, 2, 3, 4 range(1, 6) # 1, 2, 3, 4, 5 range(0, 10, 2) # 0, 2, 4, 6, 8 (с шагом 2)

4. Функции: определение и возврат значений

Функция — это именованный блок кода, который выполняет определенную задачу и может быть вызван из других частей программы.

Определение функции:

def название_функции(параметры): # Тело функции return результат # Необязательно

Что возвращает функция без return?

Если в функции нет оператора return, или если return указан без значения, функция возвращает специальное значение None. Это не то же самое, что 0 или пустая строка — None означает "ничего", "отсутствие значения".

Пример:

def приветствие(имя): print(f"Привет, {имя}!") # Нет оператора return
результат = приветствие("Мария") # Выведет: Привет, Мария! print(результат) # Выведет: None

5. Списки и основные методы работы с ними

Список (list) — это изменяемая (mutable) упорядоченная коллекция элементов, которые могут быть разных типов.

Создание списков:

# Пустой список empty_list = []
# Список с элементами numbers = [1, 2, 3, 4, 5] mixed = [1, "текст", 3.14, True] nested = [[1, 2], [3, 4]] # Список списков

Методы списков:

1. append(x) — добавляет элемент x в конец списка

fruits = ["яблоко", "банан"] fruits.append("апельсин") # ["яблоко", "банан", "апельсин"]

2. insert(i, x) — вставляет элемент x на позицию i

fruits.insert(1, "груша") # ["яблоко", "груша", "банан", "апельсин"]

3. pop(i) — удаляет и возвращает элемент по индексу i

last = fruits.pop() # Удаляет последний элемент second = fruits.pop(1) # Удаляет элемент с индексом 1

4. remove(x) — удаляет первый элемент со значением x

fruits.remove("банан") # Удаляет "банан"

5. Другие полезные методы:

fruits.sort() # Сортировка по возрастанию fruits.reverse() # Разворот списка fruits.count("яблоко") # Подсчет количества "яблоко" fruits.index("груша") # Индекс первого вхождения "груша"

6. Типы данных в Python: изменяемые и неизменяемые

Изменяемые (mutable) типы:

  • Списки (list) — можно изменять, добавлять, удалять элементы
  • Словари (dict) — можно изменять значения по ключам
  • Множества (set) — можно добавлять и удалять элементы

Пример изменяемости списка:

my_list = [1, 2, 3] my_list[0] = 10 # Изменяем элемент my_list.append(4) # Добавляем элемент print(my_list) # [10, 2, 3, 4]

Неизменяемые (immutable) типы:

  • Числа (int, float, complex) — нельзя изменить, можно только присвоить новое значение
  • Строки (str) — нельзя изменить символы, можно создать новую строку
  • Кортежи (tuple) — нельзя изменять после создания
  • Булевы значения (bool) — True или False

Пример с кортежем:

my_tuple = (1, 2, 3) # my_tuple[0] = 10 # ОШИБКА! Кортеж нельзя изменить new_tuple = my_tuple + (4,) # Создаем новый кортеж print(new_tuple) # (1, 2, 3, 4)

7. Операторы в Python: арифметические и логические

Арифметические операторы:

5 + 3 # Сложение → 8 5 - 3 # Вычитание → 2 5 * 3 # Умножение → 15 5 / 2 # Деление → 2.5 (вещественное) 5 // 2 # Целочисленное деление → 2 (важно для теста!) 5 % 2 # Остаток от деления → 1 5 ** 2 # Возведение в степень → 25

Логические операторы:

Используются для работы с логическими значениями (True и False):

1. and — логическое И (возвращает True, если оба операнда истинны)

True and True # True True and False # False

2. or — логическое ИЛИ (возвращает True, если хотя бы один операнд истинен)

True or False # True False or False # False

3. not — логическое НЕ (возвращает противоположное значение)

not True # False not False # True

Примеры в условиях:

age = 25 is_student = True
if age >= 18 and is_student: print("Совершеннолетний студент")
if age < 18 or not is_student: print("Или несовершеннолетний, или не студент")

8. Встроенные функции для работы с числами

Python предоставляет множество встроенных функций для работы с числами:

1. abs(x) — возвращает абсолютное значение (модуль) числа

abs(-5) # 5 abs(3.14) # 3.14

2. max(iterable) — возвращает максимальный элемент

max([1, 5, 3]) # 5 max(4, 2, 9) # 9

3. min(iterable) — возвращает минимальный элемент

min([1, 5, 3]) # 1 min(4, 2, 9) # 2

4. round(x, n) — округление числа x до n знаков после запятой

round(3.14159, 2) # 3.14

5. sum(iterable) — сумма элементов

sum([1, 2, 3, 4]) # 10
Важно: len() — это функция для определения длины последовательности (строки, списка, кортежа), а не только для чисел.

9. Модули в Python: импорт и использование

Модуль — это файл с расширением .py, содержащий код на Python (функции, классы, переменные).

Способы импорта:

1. Импорт всего модуля:

import math result = math.sqrt(16) # 4.0

2. Импорт конкретных функций:

from math import sqrt, pi result = sqrt(25) # 5.0 print(pi) # 3.141592653589793

3. Импорт с псевдонимом:

import math as m result = m.sqrt(9) # 3.0

Популярные модули:

  • random — генерация случайных чисел
  • math — математические функции
  • datetime — работа с датой и временем
import random random.randint(1, 10) # Случайное целое от 1 до 10

Важные моменты:

  • Модули стандартной библиотеки Python не требуют установки через pip
  • Сторонние модули устанавливаются через pip install имя_модуля
  • После импорта можно использовать все функции модуля (если они не приватные)

10. Работа с файлами: открытие, чтение, запись

Открытие файла: функция open()

file = open("example.txt", "r") # Открыть для чтения

Режимы работы с файлами:

Режим Описание
'r' Чтение (по умолчанию)
'w' Запись (перезаписывает файл)
'a' Добавление в конец файла
'x' Создание нового файла (ошибка, если файл существует)
'b' Бинарный режим (например, 'rb', 'wb')

Методы работы с файлами:

# Чтение файла content = file.read() # Читает весь файл line = file.readline() # Читает одну строку lines = file.readlines() # Читает все строки в список
# Запись в файл file.write("Текст\n") # Записывает строку file.writelines(["Строка 1\n", "Строка 2\n"]) # Записывает список строк

Важность закрытия файлов:

Файлы нужно закрывать после работы, чтобы освободить ресурсы:

1. Явное закрытие:

file = open("example.txt", "r") content = file.read() file.close() # Важно!

2. Использование контекстного менеджера (рекомендуется):

with open("example.txt", "r") as file: content = file.read() # Файл закрывается автоматически при выходе из блока with
Внимание на тест: Режим 'w' полностью перезаписывает файл, а не добавляет в него!

11. Генерация списков (list comprehensions)

List comprehension — это компактный способ создания списков в Python.

Базовый синтаксис:

[выражение for элемент in последовательность if условие]

Примеры:

# Квадраты чисел от 0 до 9 squares = [x**2 for x in range(10)] # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
# Только четные квадраты even_squares = [x**2 for x in range(10) if x % 2 == 0] # [0, 4, 16, 36, 64]
# Преобразование строк words = ["hello", "world", "python"] uppercase = [word.upper() for word in words] # ["HELLO", "WORLD", "PYTHON"]

Преимущества:

  • Более читаемый код
  • Часто работает быстрее обычных циклов
  • Компактная запись

12. Проверка типов данных: функция type()

Функция type() возвращает тип переданного ей объекта.

Примеры:

print(type(5)) # <class 'int'> print(type(5.0)) # <class 'float'> (важно для теста!) print(type("текст")) # <class 'str'> print(type(True)) # <class 'bool'> print(type([1, 2])) # <class 'list'> print(type((1, 2))) # <class 'tuple'>

Практическое применение:

value = input("Введите число: ")
if type(value) == str: print("Это строка, преобразуем в число...") number = int(value) print(f"Теперь это число: {type(number)}")

13. Кортежи (tuple): неизменяемые последовательности

Кортеж — это неизменяемая (immutable) упорядоченная последовательность элементов.

Создание кортежей:

# Пустой кортеж empty_tuple = ()
# Кортеж с одним элементом (нужна запятая!) single = (5,) # Важно: (5) - это не кортеж, а число в скобках!
# Кортеж из нескольких элементов coordinates = (10, 20) colors = ("красный", "зеленый", "синий")
# Без скобок (кортеж упаковка) numbers = 1, 2, 3 # (1, 2, 3)

Особенности кортежей:

  1. Неизменяемость — нельзя изменить после создания
  2. Быстрее списков — занимают меньше памяти, работают быстрее
  3. Используются как ключи словарей (в отличие от списков)
  4. Могут содержать разные типы данных

Операции с кортежами:

# Доступ к элементам colors = ("красный", "зеленый", "синий") print(colors[0]) # красный print(colors[-1]) # синий (последний)
# Срезы print(colors[1:]) # ("зеленый", "синий")
# Конкатенация (создание нового кортежа) mixed = colors + ("желтый",) # ("красный", "зеленый", "синий", "желтый")
# Длина кортежа print(len(colors)) # 3
# Проверка вхождения print("красный" in colors) # True

Когда использовать кортежи:

  • Когда нужна неизменяемая последовательность
  • Для возврата нескольких значений из функции
  • Как ключи в словарях
  • Когда порядок элементов важен, но менять их не нужно

Пример возврата нескольких значений:

def get_user_info(): name = "Анна" age = 25 city = "Москва" return name, age, city # Возвращает кортеж
user_info = get_user_info() # ("Анна", 25, "Москва")
